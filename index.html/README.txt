ฟาร์มสุขใจ - PWA Farm Game

ไฟล์หลัก:
- index.html
- style.css
- app.js
- manifest.json
- sw.js

วิธีใช้งาน:
1. แตกไฟล์ ZIP
2. เปิดผ่านเว็บเซิร์ฟเวอร์ (แนะนำ VS Code + Live Server หรือ GitHub Pages)
3. เปิดบนมือถือด้วย Chrome/Edge
4. เมื่อรองรับ PWA จะมีปุ่ม "ติดตั้งแอป"

หมายเหตุ: Service Worker และ PWA ต้องรันผ่าน HTTPS หรือ localhost จึงจะทำงานได้เต็มรูปแบบ
เกมบันทึกเงิน เมล็ด ผัก และของตกแต่งไว้ใน localStorage ของเบราว์เซอร์

อัปเดต: ระยะการเจริญเติบโตของพืช
- แครอท 3 ระยะ (3+5+7 = 15 วินาที)
- ข้าวโพด 4 ระยะ (4+6+7+8 = 25 วินาที)
- มะเขือเทศ 4 ระยะ (5+8+10+12 = 35 วินาที)
- ฟักทอง 5 ระยะ (6+8+10+12+14 = 50 วินาที)
แตะแปลงที่กำลังโตเพื่อดูรายละเอียดแต่ละระยะ แก้เวลาได้ที่ตัวแปร crops ใน app.js (ค่า t หน่วยวินาที)
